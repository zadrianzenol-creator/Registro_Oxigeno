# Registro Oxigeno

Aplicacion local para registro y consulta de informacion de oxigeno.

## Configuracion

1. Instala dependencias con npm ci.
2. Copia config.example.json como config.json y completa los datos locales de SQL Server.
3. No publiques credenciales de config.json; esta excluido de Git.
4. Inicia con npm start.
